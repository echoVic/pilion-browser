# 外部 Agent 授权范围

用户已确认按会话中的方案直接修改：批准一次、本任务允许、始终允许此客户端，设置中可撤销。

## 设计与边界

- 外部客户端默认仍为 ask；已有记录缺少权限字段时按 ask 处理。
- 审批增加可选 scope：once（兼容旧调用）、space、client。只有外部浏览器审批支持扩大范围，任务范围仅适用于当前活跃、归属匹配的 Agent Space。
- Space 授权存于内存，按完整 principal 隔离，跨 CLI 短连接复用；结束、空闲、接管、吊销或关闭通道时清除，重启不恢复。
- 客户端 full 权限与 token 哈希一起保存在客户端注册表；设置可恢复 ask，并清除该客户端所有临时授权。
- 审批仍验证可信窗口、用户手势、nonce、digest、连接、页面 epoch/origin；ACL、Space 归属和执行前目标校验继续生效。
- full 与内置对话的完全访问含义一致。录制技能回放、定时任务创建等专有审批继续沿用原有规则。

## Review Focus

- CLI 连接重建不能丢失任务授权；新 Space 不能继承旧任务授权。
- Space 被接管/停止/闲置后不能带着旧授权恢复。
- 错误手势、失效页面、内部 ACP/定时任务审批不能借 scope 扩权。
- 持久写入失败不能返回成功；撤回不能保留临时 full。
- 窄面板下按钮可见、操作来源与权限范围清楚。
