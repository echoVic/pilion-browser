## 1. 设计语言与核心原则

Pilion 的设计语言浓缩为一句话：

> **「Arc + Cursor / Linear 的极简现代底盘」×「Dia / Strawberry 式的几何灵气」**

浏览器是承载万千网站的画框，Agent 是与你并肩同行的副驾。整体界面必须**极致克制、现代、去噪、耐看 8 小时不累**，同时通过饱满圆润的几何比例和小面积鲜活点睛色保留亲和力与生命感——绝不冷冰冰，也绝不廉价幼稚。

### 五条核心原则

1. **底盘隐形，把空间 100% 还给网页（Arc 骨架）**：采用 **0 顶栏 + 8px 空间染色画框 + 10px 圆角视口**，所有常规浏览器控件收进左侧 224px 侧栏；右侧 Agent 面板作为同级 Split View 卡片随时可一键收起（`⌘E`）。
2. **界面 95% 纯中性黑白灰，色彩只做点睛与状态语义**：日常按钮、文字、选中态全部使用纯中性黑白灰（浅色 `#111113` / 深色 `#F4F4F5`），确保打开 GitHub Dark、飞书冷白文档或视频站时外壳绝不抢色、不显脏。
3. **现代感 = 去噪 + 单层发丝线（Cursor / Claude Code / Linear 派）**：用清晰的间距、留白与极细发丝线替代多层嵌套边框；一切“现在要做的决定”（审批、托管标签、接管、排队）固定在滚动区外。
4. **可爱来自 3 秒可画的几何比例，而非写实拟人**：品牌亲和力收口在 **「02 · 几何圆团 P」** 的饱满圆角与鲜活三色点睛上，不做写实 3D 金属，也不做带五官的卡通公仔。
5. **诚实、安全、方向盘始终在手**：高危审批卡必须完整呈现目标域名与动作语义；各空间共享登录态，空间染色仅作任务上下文区分，绝不暗示权限隔离。

### 明确禁止项（Anti-Patterns）

- **禁止系统 Emoji 充当 UI 图标**（如 🛡、🌐、⚡、✋）：全站统一使用 **1.5px 线性矢量 SVG**（Lucide 风格）。
- **禁止彩色粗左边条与多色外框警告盒**（如 3px 橙左条 + 橙外框 + 红框按钮的旧后台表单风）：改用单层纯中性发丝线浮卡 + 6px 语义圆点。
- **禁止多层套娃边框与虚线输入框**：输入框、审批卡、代码条最多保留一层结构边界。
- **禁止双层顶栏或三层堆叠面板头**：主窗口保持 0 顶栏，Agent 面板头部收敛为 **38px 单行**。
- **禁止为了“柔和”牺牲对比度**：所有文字（含占位符、时间戳、侧栏底部注记）必须满足 **WCAG 2.2 AA（≥ 4.5:1）**，交互边界 ≥ 3:1。

## 2. 品牌标志与桌面图标（02 · 几何圆团 P）

### 2.1 图形构成（100 × 100 基准网格）

仅由 **3 个饱满几何块** 组成俏皮、现代、3 秒可手绘的小写/大写过渡态 **`p`**，同时隐喻 Pilion（主驾立柱 + 伴行伙伴 + 灵动光点）：

| 元素         | 几何参数（100×100 坐标系）                          | 语义                  |
| ------------ | --------------------------------------------------- | --------------------- |
| 左侧圆角立柱 | `rect x="23" y="21" width="20" height="58" rx="10"` | 用户主驾 / 浏览器基座 |
| 右上圆球     | `circle cx="61" cy="41" r="17.5"`                   | 伴行 Agent / 视窗环   |
| 右下伴行小点 | `circle cx="62" cy="70" r="8.5"`                    | 交接与实时状态光点    |

### 2.2 品牌三色基因与全站语义映射

图标三色天然对应全站状态语义，平时藏于黑白灰界面之后，仅在 Logo 与关键状态点亮：

| 图标部位         | 主色（浅底鲜活版） | 暗夜版（深底）   | 全站语义对应                           |
| ---------------- | ------------------ | ---------------- | -------------------------------------- |
| 左柱（主驾）     | 钴蓝 `#2B62F6`     | 纯白 `#FFFFFF`   | 默认 **Arc 雾蓝** 空间、Agent 活跃执行 |

### 2.3 桌面图标与资产落位

- **桌面主标（macOS Big Sur / Tahoe 栅格）**：1024×1024 画布，圆角方标外留安全边距（约 824–936 有效主体，圆角比 22.5%，角部透明 `alpha = 0`）。
  - 浅色主标：冷白微渐变底 `#FFFFFF → #F3F4F8` + 极细内高光描边 + 钴蓝/珊瑚橘/暖阳黄三色几何 P。
  - 深色版（`build/icon-dark.png`）：深炭蓝黑底 `#1B1F2A → #0E1016` + 纯白/冰蓝/暖琥珀三色几何 P。
- **品牌锚点微标（左上角应用标、Agent 顶栏与消息头像、新标签页、对话空态）**：统一使用三色几何圆团 P（浅色：钴蓝/珊瑚/暖金；深色：纯白/天蓝/暖金），在克制的黑白灰底盘上成为唯一且有辨识度的品牌点睛。
- **单色微标（`build/logo.svg`）**：仅用于菜单栏模板图标（macOS Template Image）或纯单色印刷/文档场景（`currentColor`，左柱 100%、右上圆球 65% 不透明度、右下小点 100%）。
- **落位文件**：`build/logo.svg`、`build/icon.svg`、`build/icon.png`（1024×1024）、`build/icon-dark.png`。

## 3. 主窗口架构：纯正 Arc 0-顶栏骨架

### 3.1 空间布局与尺寸

```
┌── 8px 空间染色外框（默认 Arc 雾蓝）───────────────────────────┐
│ ┌─ 左栏 (224px, 可 ⌘S 隐藏) ─┐ ┌─ 网页主视口 (flex:1) ─┐ ┌─ Agent 分屏 (380px, 可 ⌘E 收起) ─┐ │
│ │ ● ● ●   [侧栏] < > ↻      │ │                       │ │ ● 会话标题 ⌄       [审计][+][🕒] │ │
│ │ [🔒 domain.com      📋]   │ │  WebContentsView      │ │ ──────────────────────────────── │ │
│ │ [Fav1]  [Fav2]  [Fav3]    │ │  10px 圆角            │ │ [全宽 Prompt 块]                 │ │
│ │ ● 工作区 ⌄            ⋯   │ │  距离顶/底仅 8px       │ │ ▸ 已完成 4 项浏览器操作 2.3s      │ │
│ │   Pinned 固定标签         │ │                       │ │ Agent 文本与表格                 │ │
│ │ ── 今天 · 24h归档 ──      │ │                       │ │ ──────────────────────────────── │ │
│ │ + 新建标签页          ⌘T  │ │                       │ │ [悬浮坞：托管标签 / 审批 / 队列]  │ │
│ │   Today 临时标签          │ │                       │ │ [悬浮 Composer：@ / 权限 模型 ↑] │ │
│ │ [实时 Agent 状态/接管条]  │ │                       │ │                                  │ │
│ │ [归档]  ● ○ ○ ○  [Agent] │ │                       │ │                                  │ │
│ └───────────────────────────┘ └───────────────────────┘ └──────────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────────────────────────────┘
```

- **外框与间隙**：全窗口 `padding: 8px; gap: 8px`，网页视口与 Agent 分屏卡片统一 `border-radius: 10px`。
- **Electron 跨平台适配**：
  - macOS 使用 `titleBarStyle: 'hiddenInset'`，交通灯自然落入左栏首行左侧；
  - Windows / Linux 使用低饱和实色或微渐变画框底色，**不依赖系统毛玻璃半透明**，保证三端视觉与性能一致；
  - 打开 `⌘T` 命令栏或 `⌘⇧O` 任务总览浮层时，沿用现有机制隐藏原生 `WebContentsView`（`visible: false`），遮罩使用纯半透明深色蒙层（`rgba(0,0,0,0.34)`），不依赖假想的实时网页背景模糊。

### 3.2 左栏解剖（224px，Arc 0 顶栏整体极简布局）

1. **Row 1 顶部控制行（32px）**：左侧预留 macOS 交通灯避让（`padding-left: 72px`），右侧为统一 14px 图标 `← → ↻` 与侧栏收起钮（`⌘S`）；侧栏收起态悬停同样保持 `padding-top: 36px`，避免展开按钮与交通灯碰撞。
2. **Row 2 紧凑 URL 胶囊（34px）**：磨砂胶囊展示当前主域名，点击唤起 `⌘T` 命令栏；右侧内置经典五角星收藏钮（`☆`/`★`，已收藏琥珀实心）与 `⌘T` 键标。
3. **Row 3 空间切换行（32px）**：左侧 `[三色 PilionMark 19px] 我的工作区 ▾`；右侧仅放扩展拼图图标（Chrome 风格正放拼图，顶/右凸起 + 左侧内凹半圆缺口）与 `⋯` 浏览器工具菜单；**仅当 Agent 面板处于关闭态时**，此处浮现克制的 `AI` 胶囊一键唤起 Agent 面板（避免与侧栏收起按钮视觉重复）。
4. **中间内容区（`flex: 1` 唯一滚动）**：Favorites 3 列图标瓷砖、Pinned 固定标签与 Today 临时标签区；切换至非浏览器视图时，顶部自然浮现 `← 返回浏览器` 轻返按钮。
5. **底部双层极简坞**：
   - **Layer A（资料库图标坞）**：6 枚统一 15px 图标横排（书签 / 浏览历史 / 下载 / 对话记录 / 技能库 / 已归档标签），带极细计数微点；再点当前激活项可切回浏览器。
   - **Layer B（空间点 + 工具栏）**：左侧 Arc 风格空间圆点快切；右侧统一 14px 工具图标（录制 / 扩展与数据 / 设置 / 主题切换）。

> **侧栏收敛约定**：取消占满半屏的 6 行 SaaS 文字导航菜单与重复的 `+` 按钮，将全部垂直空间让位给真实标签页。

### 3.3 空间切换面板（去拥挤规范）

点击左栏空间标题展开浮层（`width: 320px`，`border-radius: 16px`）：

- **我的空间**：行高 36px（当前空间 38px 白/高亮卡面），显示「8px 空间色点 + 完整空间名（优先占满，至少留 ≥176px）+ 右侧标签数 + 低透明度 `⋯` 菜单」。
- **Agent 空间**：
  - **外露区**（折叠态始终可见）：所有 **「等待确认」**、**「已接管 · 待交还」** 与 **「运行中」** 的 Agent 空间，每行**最多 1 个显式按钮**（查看 / 交还 / 接管），杜绝多按钮堆砌。
  - **折叠区**：所有已结束会话收进 `N 个已结束会话 ▸`（总计 ≤ 8 条时一次展开完，不做二级折叠）。
- **行尾 `⋯` 菜单**：打开会话 / 转为我的空间 / 重命名 / 分割线 / 删除（危险红，永不贴紧主操作按钮）。
- **底部行**：`+ 新建空间` + 右侧注明 `各空间共享登录态`。

## 4. Gemini 风格双形态 Agent 协作面板（默认关闭 + 独立悬浮窗 / 右侧停靠）

吸收 **Gemini in Chrome** 的呼吸感空态、独立可拖拽悬浮窗体验，同时保留 **Cursor / Claude Code** 级的安全审批与工具时间线信息密度。

### 4.1 默认关闭与双形态切换

- **默认状态**：应用启动时 Agent 面板**默认关闭**，将 100% 宽度留给浏览视口；需要时点击左栏克制的 `AI` 胶囊或按快捷键唤起（优先恢复上次偏好形态，首次默认以独立悬浮窗弹出）。
- **独立悬浮窗（`?window=agent` 原生透明无框子 `BrowserWindow`）**：默认 `396×620`，`parent: mainWindow` 永远悬浮于主窗口与原生 `WebContentsView` 网页之上，可自由拖动位置与缩放，20px 大圆角与原生窗口阴影，严格复用主进程 `trustedRenderer` 鉴权与 `isTrusted` 审批链路。
- **右侧停靠 Split View**：点击顶栏 `◫`（停靠到右侧 / 切换为悬浮窗）一键无损切换为右侧 380px 圆角分屏（320–480px 可调），共享 8px 空间画框间隙。
- **底部氛围柔光**：空态在底部铺设克制的径向冷蓝柔光（浅色透明柔蓝 / 深色曜石 `#0e1015` 衬深海蓝光晕），与 Gemini 悬浮窗视觉气质呼应。

### 4.2 四层结构（仅第 2 层滚动）

| 层级                     | 高度 / 规格            | 内容与行为                                                                                                                                                                                     |
| ------------------------ | ---------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **1. 极简无压迫顶栏**    | 固定 **42px**          | 空态隐藏底线且全行支持拖拽浮窗；左：低饱和会话标题下拉（悬停浮现）；右：仅留 4 枚轻图标 `+`（新对话）、`⋮`（更多菜单：对话/审计切换、任务总览、管理 Agent）、`◫`（悬浮/停靠切换）、`✕`（收起） |
| **2. 滚动内容区**        | `flex: 1` 唯一滚动     | 空态为居中 34px `PilionMark` + 20px 主问候语 + 贴近输入框的自适应圆角建议胶囊（`.s-pill`）；有消息时展示全宽 Prompt 块 + 推理折叠 + 可折叠工具时间线 + 流式 Markdown/表格                      |
| **3. 悬浮工作坞**        | 条件渲染，固定滚动区外 | 按优先级渲染：高危审批卡 / 人工接管条 / 托管标签工作集（Working Set）+ 计划进度 + 待发队列                                                                                                     |
| **4. 集成圆角 Composer** | 固定底部               | 圆角 18px 集成卡：顶部内嵌 Gemini 式 `正在分享“标签名”标签页 ×` 状态行 + 自增文本域 + 底部极简行（左侧 `+` 菜单收敛图片/`@`/`/` + 权限芯片 + Agent 选择器 + 右下 28px 圆形发送/连接钮）        |

### 4.3 核心组件规格

- **全宽 Prompt 块（替代聊天气泡）**：`background: var(--panel-tint)`、`border-radius: 12px`、内边距 `10px 12px`，顶部小行展示本次附带的 `@标签页` 上下文与时间戳，正文 13px，无冗余气泡尾巴与外框。
- **可折叠工具时间线（Step Timeline）**：
  - 连续已完成的浏览器动作自动折成一行：`▸ 已完成 N 项浏览器操作 · 2.3s`；
  - 展开后左侧 1px 细竖轨（`--rail`）串联每步：`状态图标 + 等宽动词(navigate/observe/fill) + 参数摘要 + 耗时`，点击单步可展开目标 URL / DOM 摘要；
  - 当前正在执行的步骤始终外露在轨道底部（青蓝细 spinner），同一 `toolCallId` 原地更新。
- **托管标签工作集条（Browser Working Set）**：运行中停靠在输入框上方，单行展示 `▸ 🌐 N 个托管标签页` + `2/4 步` 计划切换 + `接管` + `停止`；展开后可对单个标签页执行「查看 / 接管」。
- **现代高危审批卡（单层发丝线 + Split Button）**：
  - 容器：纯中性浮卡（`--panel-elevated` + `--shadow-card`），**无橙色外框、无 3px 彩色左条**；
  - 顶行：6px 琥珀脉动点 + 简洁动词标题（如「确认点击操作」）+ 右侧完整域名（如 `mall.example.com`）；
  - 命令条：无外框微灰圆角条（`--panel-tint`），等宽展示 `click "提交订单"` + 右侧可展开「详情」（含完整 URL、元素角色、最大高 120px 内部滚动）；
  - 操作行：左侧无框幽灵钮 **`拒绝` + `Esc` 键标**（仅 hover 泛浅红）；右侧纯黑白主色 **Split Button**：**`批准一次 ⌘↵ | ⌄`**，点 `⌄` 展开二级选项：**仅批准这一次 / 本空间免问 / 拒绝并人工接管**；提交中两钮同时 disabled 防重放（沿用现有 `approvalId + nonce + actionDigest` 校验链路）。
- **排队与打断**：运行中按 `Enter` 入队并清空输入（同时右下角提交按钮在有字时保持可点「入队」状态，不与停止按钮重复）；待发队列条提供「撤回 / 删除 / 立即打断发送 `⌘↵`」。
- **历史对话恢复三态（只渲染主进程快照）**：
  - `resuming`：顶栏蓝点脉动 + 底部中性状态条「正在连接 {AgentName} 并恢复对话…」+ 输入框禁用；
  - `agent-missing`：悬浮单层卡提示「原 Agent（{AgentName}）不可用」+ 主钮「选择其他 Agent…」+ 必现说明「切换其他 Agent 将开始全新会话，不携带此前上下文」；
  - `resume-failed`：区分 `connection`（连接超时）与 `concurrency_limit`（并发上限 `n/n`）文案 + 「重试」主钮；三态下历史消息均可自由滚动浏览。
- **审计流视图**：顶栏一键切换，按时间倒序以极简列表呈现本会话全部浏览器工具调用、免审/授权范围与耗时。

## 5. 双主题 Design Tokens（WCAG 2.2 AA 全量达标）

所有文字对比度经脚本实算 **≥ 4.5:1**，图形/强边界 **≥ 3.0:1**（`0 FAIL`）。

### 5.1 空间画框色板（8px 外框 + 左栏背景）

### 5.3 排版、圆角、阴影与动效

- **字体栈**：`-apple-system, BlinkMacSystemFont, "SF Pro Text", "Inter", "PingFang SC", "Noto Sans SC", sans-serif`；等宽 `ui-monospace, "SF Mono", Menlo, Consolas, monospace`。
- **字号刻度**：`11px`（时间/快捷键标/微注记）、`12px`（工具行/侧栏标签/芯片/审批操作）、`13px`（消息正文与输入框）、`15px`（空态标题）；正文行高 `1.5`，代码 `1.55`。
- **圆角刻度**：`6px`（芯片/微按钮）、`8px`（列表项/命令条）、`10px`（网页视口与 Split View 分屏卡）、`12px`（Prompt 块/悬浮审批卡）、`16px`（Composer 浮卡/Popover/空间切换面板）。
- **动效与降级**：微交互 `120ms`、面板展开收起 `180–200ms`，统一 `cubic-bezier(0.2, 0, 0, 1)`；在 `prefers-reduced-motion: reduce` 下关闭脉动与旋转动画。
- **键盘与无障碍**：所有交互控件具备 2px 可见 `:focus-visible` 环；中文输入法 `isComposing` 期间禁止触发发送/快捷键；审批卡与错误区用 `role="alert"`，运行状态用 `role="status"` + `aria-live="polite"`。

## 6. 产品与安全不变量（重构不得破坏）

1. **设置窗口边界（见 `settings-and-menu.md`）**：独立懒创建窗口，固定「通用 / 浏览器 / 快捷键 / Agent」四页；审批开关、蒙层、全局 `full` 默认权限、证书与私网策略**永不进设置 UI**。
2. **审批防重放链路**：审批决策继续携带 `approvalId`、`nonce`、`actionDigest` 与用户手势 token；Split Button 内的「本空间免问」直接映射既有空间级审批作用域。
3. **附件与链接安全**：渲染层 + 主进程双重 Zod 校验，持久化不存 base64；Markdown 链接经受控浏览器打开。
4. **原生视口边界同步**：侧栏（`⌘S`）与 Agent 分屏（`⌘E`）收起/展开以及窗口缩放时，通过 `ResizeObserver` 精准同步 `WebContentsView` 矩形边界，永不出现 DOM 盖不住原生视图或残影问题。

## 7. 前端技术栈替换建议与分期路线图

为了摆脱旧版聊天组件库对布局与工具折叠的束缚，对话面板建议直接替换技术栈：

- **滚动与虚拟化**：移除 `@assistant-ui/react` 线程黑盒，改用 `@tanstack/react-virtual` + 自控贴底滚动（支持可变高度的可折叠工具组与长对话不掉帧）。
- **状态管理**：`zustand`（或 `useSyncExternalStore`）承接主进程快照，按 `conversationId` 切片隔离草稿、队列与展开态。
- **浮层与命令交互**：复用项目已有的 `@radix-ui/react-*`（Dialog / Popover / DropdownMenu），搭配 `cmdk` 实现会话搜索、`@标签` 引用与 `/` 技能选择器。
- **流式 Markdown 与代码**：`react-markdown`（或 `streamdown`）+ `shiki` 增量高亮。
