# Pilion「Agent 对话面板」重设计 · 前端验收清单

对照《Pilion「Agent 对话面板」重设计 · 设计规范 v1.1》逐项验收。每个条目可独立勾选；带 ✱ 的为**阻断项**（不通过则验收失败）。

## A. 尺寸与布局

- [ ] A1 ✱ 面板默认宽度 368px；可拖拽/配置至 300px；收起后为 44px 图标条
- [ ] A2 ✱ 七层结构顺序：标签行(40) → 头部(46) → 状态条(34) → 滚动区(flex) → 审批坞(条件) → 任务控制条(条件) → 输入区；仅滚动区滚动
- [ ] A3 头部：头像 26×26 / 圆角 8；图标钮 28×28
- [ ] A4 状态条分段控件高 24px（容器内边距 2、选中项浮起带 `--shadow-1`）
- [ ] A5 滚动区内边距 12/12/16、消息间距 12；滚动条 8px 细样式
- [ ] A6 审批坞、任务控制条在滚动区外固定渲染，内容再长也不把按钮推出视口
- [ ] A7 300px 档：标签 ≤96px、状态条仅状态点、芯片截断、快捷键提示隐藏、用户气泡 94%、审批按钮纵排、区域内边距 8px
- [ ] A8 面板收起/展开动画 240ms `cubic-bezier(.2,0,0,1)`；收起时各会话草稿按会话 ID 保留并恢复
- [ ] A9 滚动区上下边缘 14px 渐隐（`--chat-bg`→透明，`pointer-events:none`）

## B. 颜色 Token

- [ ] B1 ✱ 深色/浅色两套 `--chat-*` 变量按规范 §7.2 落地，hex 值逐项一致
- [ ] B2 ✱ 强调色为蓝绿系（深 `#2dd4bf` / 浅 `#0f766e`），界面无大面积靛蓝/紫色
- [ ] B3 代码块两主题统一深底 `#121316` + 字 `#d9dce3`
- [ ] B4 交互组件边界用 `--chat-border-strong`（深 `#767a8a` / 浅 `#828592`）；装饰分隔线才可用 `--chat-border`
- [ ] B5 用户气泡：深 `#1f3330` 底 `#5d8d83` 边 / 浅 `#dcefeb` 底 `#43897c` 边；圆角 `10 4 10 10`
- [ ] B6 语义色不混用：青=运行/Agent、琥珀=审批/接管、红=错误/停止；无纯颜色传达状态（均伴随文字或图标）
- [ ] B7 抽查对比度：正文 ≥4.5:1、次要文字 ≥4.5:1、占位符 ≥4.5:1、组件边界 ≥3:1、焦点环 ≥3:1（规范 §7.2 附实算值）

## C. 字体与排版

- [ ] C1 ✱ 字号只出现 11/12/13/14/16px 五档（代码 12px 等宽）
- [ ] C2 正文行高 1.45，标题 1.2，代码/推理 1.55；字重仅 400/500/600
- [ ] C3 时间戳、徽标、提示语 11px；无 10px 以下正文（徽标数字 10px 除外）
- [ ] C4 中文输入法组合期间（`isComposing`）不受控回写、快捷键不触发

## D. 组件状态

- [ ] D1 ✱ 流式回复：输出中尾部有 2×13px 青色闪烁光标；完成后消失；消息操作行流式中隐藏
- [ ] D2 ✱ reasoning：`<details>` 可折叠，展开/收起箭头旋转 180ms；运行中默认展开、完成后默认收起；正文区 >180px 内部滚动
- [ ] D3 ✱ 工具行三态：spinner（青、0.8s）→ 对勾（青）→ 感叹号（红）；同 turn 同 `toolCallId` 原地更新、不重复插入
- [ ] D4 计划卡：done 青底对勾+划线灰字 / current 青环形+600 字重 / pending 灰框灰字；进度徽标 `n/m`
- [ ] D5 ✱ 审批坞：琥珀左色条 + 「N 项待确认」计数；详情展开最大高 120px 内部滚动；拒绝(ghost 红)/批准一次(青实底)始终可见；提交中两钮 disabled
- [ ] D6 ✱ 任务控制条：运行中=「接管」主钮+「停止任务」ghost；人工=「继续任务」主钮+「停止任务」ghost；空闲不渲染
- [ ] D7 ✱ 排队：运行中 Enter 入队并清空输入；队列行有序号/文本截断/撤回/删除；回合结束（成功、失败、取消）自动合并发出；⌘/Ctrl+Enter 打断后立即合并发送
- [ ] D8 ✱ 附件：缩略图 52×52 + 删除钮 + 计数 `n/5`；>5 张或单张 >5MB 显示错误提示；Agent 无图片能力时按钮 disabled 且提示
- [ ] D9 ✱ `/` 技能选择器：`/` 开头无空格展开；↑↓/Enter/Esc 可操作且不落入发送逻辑；选中项青 soft 底；`role=listbox/option`
- [ ] D10 技能提案面板：青色边卡；未选目标技能时「采用为修改」disabled；错误 `role="alert"`
- [ ] D11 权限/模型芯片在输入卡内：当前值青 soft 底标识；运行中锁定；模型仅列实际可选项
- [ ] D12 复制按钮：点击变青色对勾 + `aria-label`「已复制」，1.6s 还原；失败显示「复制失败，重试」
- [ ] D13 空态：图标 + 标题 + 副文案 + 3 建议卡（hover 青边青底）；点击填充输入框；未连接 Agent 时聚焦 Agent 选择器并出提示条
- [ ] D14 发送钮三形态：空闲青色↑ / 运行中红色■（停止）/ 未连接=插头图标
- [ ] D15 自动滚动：流式贴底；上翻即暂停并显示「回到底部」30×30 圆钮（距底 14px 居中）；点击回底
- [ ] D16 出错：`MessageNotSentError` 时草稿回填输入框，红色 `role="alert"` 卡片提示，不自动重发
- [ ] D17 人工接管：占位「补充说明后发送，继续任务…」；琥珀提示条；底部信息行「浏览器由你掌控」；Enter 发送补充说明（不带附件）
- [ ] D18 ✱ 恢复中（resuming）：头部显示**该对话的 Agent 名**（非上一条对话的）+ 名前青 spinner + 琥珀脉冲点；状态条「正在连接 {AgentName} 并恢复对话…」；历史消息可滚动浏览；输入框 disabled（placeholder「正在连接原 Agent，恢复后即可继续输入…」）且发送钮 disabled；恢复完成后输入自动启用、焦点移回输入框
- [ ] D19 ✱ 原 Agent 不可用（agent-missing）：头部 Agent 名 + 琥珀「不可用」标签；warn 通知卡含「选择其他 Agent…」按钮 + 11px 说明「选择其他 Agent 将开始全新会话，不会带上此对话之前的上下文」（说明必须出现）；历史可浏览；输入 disabled
- [ ] D20 ✱ 恢复失败（resume-failed）：danger 通知卡 + 「重试」按钮；两种原因文案必须区分且由快照字段驱动——连接超时：「无法连接 Agent 服务（连接超时）…」/ 并发上限：「已达该 Agent 的并发会话上限（n/n）…」；重试后回到 resuming 表现；历史可浏览；输入 disabled
- [ ] D21 恢复三态：输入卡片 opacity 0.72、`cursor:not-allowed`；权限/模型芯片只读；任务控制条不渲染
- [ ] D22 ✱ 前端只渲染主进程快照字段（`conversation.agentName` / `resumeFailure.reason` 等），不自行推断或缓存 Agent 身份；快照更新即重渲染

## E. 多会话

- [ ] E1 ✱ 会话标签行：横向滚动 + 左右 8px 渐隐；选中青 soft 底；待审批会话显示琥珀角标
- [ ] E2 切换会话重建独立 runtime；草稿/队列/审批按会话隔离
- [ ] E3 新会话钮、历史对话入口可用；「活动」分段计数与该会话待审批数一致
- [ ] E4 ✱ 打开历史对话即触发主进程按 `conversation.agentId` 自动连接原 Agent；选中后头部 Agent 选择器立即切换为该对话的 Agent（不显示上一条对话的）

## F. 键盘与焦点

- [ ] F1 ✱ Tab 可达全部 7 层的交互元素；焦点环 2px `--chat-focus` + offset 2px，清晰可见
- [ ] F2 ✱ Enter 发送 / 运行中 Enter 入队 / ⌘/Ctrl+Enter 打断并发送 / Shift+Enter 换行
- [ ] F3 Esc 关闭技能选择器/浮层，不清空草稿
- [ ] F4 审批按钮、details 可 Enter/Space 操作；提交中防回车重放
- [ ] F5 `prefers-reduced-motion: reduce`：spinner 静态化、呼吸/光标闪烁停用
- [ ] F6 恢复三态焦点顺序：标签行 → 头部 Agent 入口 → 视图分段 → 滚动区 → 通知卡操作按钮（「选择其他 Agent…」/「重试」）→ 输入框（disabled 自动移出 Tab 序，Tab 不可达）；恢复成功/选择其他 Agent 后焦点回到输入框

## G. aria / 读屏

- [ ] G1 ✱ 全部图标钮有 `aria-label`（收起面板、新对话、添加图片、移除附件、撤回、删除、复制、回到底部、停止任务…）
- [ ] G2 面板 `role="region" aria-label`；分段/标签行 `aria-selected` / `aria-pressed`
- [ ] G3 工作中胶囊、排队列表、提示条 `role="status"`；错误 `role="alert"`
- [ ] G4 技能选择器 `role="listbox"/"option"` + `aria-selected`
- [ ] G5 复制按钮 `aria-label` 随结果状态切换
- [ ] G6 输入框 `aria-label="输入任务"`，占位符随状态切换仍可读
- [ ] G7 恢复三态：resuming 状态条与 notice `role="status"` + `aria-live="polite"`；agent-missing / resume-failed 通知卡 `role="alert"`；播报内容含 Agent 名称与失败原因；头部 Agent 入口 `aria-label` 含连接状态（如「正在连接此对话的 Agent：X」/「此对话的 Agent：X（不可用）」）

## H. 主题

- [ ] H1 ✱ 深色 / 浅色 / 跟随系统三档正确切换（`data-theme=dark|light|auto` + `prefers-color-scheme`）
- [ ] H2 主题切换仅换 `--chat-*` 变量，无组件级硬编码色
- [ ] H3 ✱ 两主题下逐状态视觉与 24 张对照截图一致（16 张基础 + 2 张补充单图 + 6 张恢复场景）

## I. 数据与安全（沿用既有约束，UI 不得破坏）

- [ ] I1 审批决策仍携带 approvalId + nonce + actionDigest + 手势 token；过期/重放拒绝
- [ ] I2 复制仅限当前对话已有消息 ID；链接经受控浏览器打开
- [ ] I3 附件经 Zod 双重校验（渲染层 + 主进程）；持久化不存 base64
- [ ] I4 排队合并发出走 `dispatchPrompt`，主进程未接收时恢复草稿
- [ ] I5 权限模式活跃任务期间禁止切换的锁定态在 UI 上体现（disabled + 提示）
